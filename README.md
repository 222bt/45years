# 45년

> 어떤 어른이 될까?

0세에 태어난 아이가 45세 어른이 될 때까지, 한 해 한 해의 선택으로 인생을 키워 가는 텍스트 성장 시뮬레이션 게임입니다.
설치 없이 브라우저에서 바로 플레이할 수 있고, 한 판은 40분~1시간 정도 걸립니다.

## 게임 소개

- **능력치 6가지**: 지능 · 운동 · 손재주 · 감성 · 매력 · 의지. 그리고 행복이 있습니다.
- **성장 단계 5개**: 아기 시절 → 초등학생 → 청소년기 → 청년기 → 어른의 시간. 한 판에 40개 남짓의 사건을 겪습니다.
- **판정 도전**: 반장 선거, 고백, 마라톤, 선발 시험처럼 능력치에 따라 성공 확률이 달라지는 선택이 있습니다.
- **습관**: 단계가 끝날 때마다 하나씩 얻으며, 이후 성장 방향이 달라집니다.
- **반려동물**: 보호소에서 강아지나 고양이를 데려와 직접 이름을 지어 주고, 함께 자라고, 언젠가 떠나보냅니다.
- **진로**: 고등학교 졸업 후 대학 진학, 바로 취업, 창업, 여행 중 하나를 고릅니다. 대학은 지능과 성적에 따라 명문대부터 지방 국립대, 예체능 실기 전형, 재수까지 갈립니다.
- **연애 · 결혼 · 비혼**: 결혼, 함께 살기, 혼자의 삶, 친구들과 함께 사는 집까지 여러 갈래가 있습니다.
- **숨은 수치**: 편한 선택은 고립 · 빚 · 게으름을 조용히 쌓습니다.
- **엔딩 34개**: 직업 엔딩, 가족 엔딩, 특수 엔딩, 배드 엔딩이 있으며 엔딩 도감에 모입니다.
- **칩튠 BGM과 효과음**: Web Audio로 직접 합성하며, 설정에서 볼륨을 조절할 수 있습니다.
- **자동 저장**: 진행 상황과 엔딩 도감은 브라우저(localStorage)에 저장됩니다.

## 플레이하기

### 내 컴퓨터에서
`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

### GitHub Pages로 공개하기
1. 이 폴더의 파일을 새 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**로 들어갑니다.
3. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
4. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/`에서 게임이 열립니다.

## 파일 구성

```
.
├── index.html                  게임 전체 (HTML · CSS · JavaScript 한 파일)
├── fonts/
│   ├── NeoDunggeunmo.woff      Neo둥근모 글꼴
│   └── OFL.txt                 글꼴 라이선스
└── README.md
```

외부 라이브러리나 빌드 과정 없이 순수 HTML, CSS, JavaScript로 만들어졌습니다.

## 고쳐 보기

모든 내용은 `index.html`의 `<script>` 안에 있습니다.

| 바꾸고 싶은 것 | 찾을 곳 |
|---|---|
| 사건과 선택지 | `const EV=[ ... ]` |
| 엔딩 문구 | `const ENDINGS=[ ... ]` |
| 엔딩 조건 | `function decideEnding()` |
| 습관 | `const TRAITS`, `const TRAIT_NAMES` |
| 단계별 사건 수 | `const STAGES` |
| 배경음악 | `const SONGS`, `const PAT` |
